The fonts Discord members can give their names, matching the weights Discord's
client loads. From the google/fonts repository's `ofl` folder, except Sinistre,
from github.com/collletttivo; all unmodified, each with its SIL Open Font License
1.1 as `OFL-*.txt`. Néo-Castel by Max Lillo is the WOFF2 from hunterirving.com/git/zine_studio
(`resources/fonts/Neo-castel/`) converted to OTF, glyphs unchanged. Its licence
is the OIFL, Max Lillo's French text of the SIL Open Font License 1.1, kept
beside it as `LICENCE-neocastel-OIFL.txt`; its Reserved Font Name is Ébullition.

MuseoModerno, Pixelify Sans, Orbitron, Playpen Sans and Sinistre are static cuts
made from their variable fonts, at the weights and scales Discord's client draws
those names in, so they are modified from upstream: keep that in mind, and check
each font's Reserved Font Name terms, before publishing them.
